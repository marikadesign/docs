#コンセプト / 思想
- サービスの目的：兼業Webコーダー・Jinのポートフォリオ。採用担当とエンドクライアント双方に対し、コーディングスキルと人間的誠実さを一度で伝える
- ターゲット：業務委託を検討する採用担当者（20〜40代）、はじめてWeb制作を依頼するtoCクライアント（30〜50代）。どちらも「信頼できるか」を最初の判断軸にする
- 提供価値（機能的）：コーディング品質・フロー・料金感が一画面で把握できる
- 提供価値（感情的）：消防士という本業から滲む誠実さと責任感を感じ、安心して任せられると思える
- 体験の方向性：誠実 × ギーク × 静かなインパクト
- 避けたい印象：WordPressテーマの量産感、情報過多なうるさいレイアウト。理由：Jin本人のスキル感と人柄が埋もれる

#ビジュアル方針
- 全体トーン：洗練 × 力強い。ダーク・ライトのセクション交互構成でメリハリを出す
- 余白：広め。セクション間 120px、コンテンツ内 48〜64px
- デザインの主役：テキスト（FVはテキスト主役、制作実績セクションで画像を前面へ）

#カラーパレット
- ベースカラー：#f8f8f8（サイト全体の地色）
- 背景カラー（ダークセクション）：#344651（ヘッダー・FV・Serviceセクション）
- 背景カラー（ライトセクション）：#f8f8f8（Works・About・QA・Contact）
- セクション区切り補助：#c4c4c4（ボーダー・ライン）
- テキストカラー（ライト地）：#1b1d1b（見出し・本文）
- テキストカラー（ダーク地）：#f8f8f8（見出し）/ #9c9fa1（補足・サブテキスト）
- アクセントカラー：#5BA4B7（#344651の明度を上げた派生ティール）<補完：クライアント未定のため、ベース色系統を維持しつつCTAで判別できる明度差を確保した色を選定>
- アクセントの用途：CTAボタン・リンクホバー・フロー番号・重要な強調ライン

#タイポグラフィ
- フォント（和文・本文）：Noto Sans JP（Google Fonts）。理由：誠実さ・可読性・中立的なゴシック体
- フォント（欧文・見出し）：Cormorant Garamond（Google Fonts）。理由：セリフの主張が控えめで品格があり、和文と干渉しない
- フォント（和文・見出しアクセント）：Noto Serif JP（Google Fonts）。理由：ヒアリングの「明朝体は見出しアクセントとして可」に準拠
- 見出しの印象：細め〜標準（Cormorant Garamond 400〜600）
- 本文の行間：ゆったり（1.8）
- 見出し行間：1.3
- 文字詰め：normal（和文）/ tight（欧文大見出し、letter-spacing: -0.02em）
- フォントサイズスケール：
  - 大見出し（FV）：clamp(48px, 6vw, 80px)
  - セクション見出し：32px（デスクトップ）/ 24px（モバイル）
  - サブ見出し：18px
  - 本文：15px
  - 補足テキスト：13px

#コンポーネント方針
- ボタン（CTA）：角張り（border-radius: 2px）、塗りあり、背景 #5BA4B7、テキスト #f8f8f8、padding: 14px 40px
- ボタン（セカンダリ）：角張り、枠線のみ（border: 1px solid #344651）、テキスト #344651、padding: 12px 32px
- カード（Works）：影なし、枠線なし、背景なし。画像＋テキストの素のグリッド配置でシンプルに
- ナビゲーション：固定（position: sticky）、スクロール時に背景 #344651 + box-shadow でフローティング感
- リンク：控えめ（色のみ）、ホバー時に #5BA4B7 + アンダーライン transitionで反応を見せる
- アイコン：source/image の SVG をインライン使用。色は #9c9fa1（ライト地）/ #f8f8f8（ダーク地）に変更

#レイアウト方針
- 基本構造：1カラム（縦スクロール1ページ）
- 余白スケール：8px基準。主要スペース 8/16/24/32/48/64/96/120px
- コンテンツ最大幅：1100px、中央揃え、左右padding 40px（モバイル 20px）
- セクション分け：背景色切り替え（ライト #f8f8f8 / ダーク #344651 の交互）
- 情報密度：低〜中（FVは1メッセージ、各セクションは1役割1構成）
- FV構成：テキスト左・制作物スライダー右の2分割。スライダーはCSSのみで実装し、コーダースキルを表現
- Works構成：3カラムグリッド（デスクトップ）/ 1カラム（モバイル）。サムネイル＋タイトル＋タグ
- Service構成：3列アイコン＋テキストカード、フローは縦ステップ、料金は別ブロック
- About構成：テキスト左・写真右の2分割（将来的に写真差し替え前提で placeholder 対応）<補完：ヒアリングに写真は後日撮影とあるため>
- QA構成：アコーディオン形式。JavaScriptで開閉アニメーション
- Contact構成：入力フォーム（名前・メール・内容・送信ボタン）1カラム

#NGルール
- やらないデザイン：グラデーション多用・丸いバブル装飾・大量のアイコンアニメーション・派手なパーティクル背景
- 禁止事項：Google Fonts以外のフォント使用 / 外部画像の参照 / 絵文字の使用 / セクションの追加・順序変更
- 崩したくないポイント：ダーク（#344651）とライト（#f8f8f8）の二色軸。ここを崩すと「誠実さの中のインパクト」が失われる
